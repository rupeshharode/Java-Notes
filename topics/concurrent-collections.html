Concurrent Collections

ConcurrentHashMap, CopyOnWriteArrayList and blocking queues.

concurrencycollectionsthread-safe

Concurrent collections are thread‑safe data structures in Java (java.util.concurrent) that allow safe modifications in multi‑threaded environments. Internally, they use different strategies to ensure thread safety:

🔑 Approaches Used Internally Compare‑And‑Swap (CAS)

Lock‑free mechanism.

Ensures atomic updates by checking the expected value against the current value.

Example: ConcurrentLinkedQueue, AtomicInteger.

Fine‑grained Locking

Instead of locking the entire structure, only small portions (like buckets in ConcurrentHashMap) are locked.

Improves concurrency because multiple threads can work in parallel.

Copy‑On‑Write

Readers always get a consistent snapshot.

Writers create a new copy when modifying.

Example: CopyOnWriteArrayList, CopyOnWriteArraySet.

Best for read‑heavy, write‑light scenarios.

Blocking with Conditions

Threads wait if the queue is full (producers) or empty (consumers).

Example: BlockingQueue implementations (ArrayBlockingQueue, LinkedBlockingQueue).

Perfect for producer‑consumer problems.

✅ Example Interview Answer "Concurrent collections are thread‑safe alternatives to normal collections. Internally, they use CAS for lock‑free atomic updates, fine‑grained locking to avoid blocking the whole structure, copy‑on‑write for read‑heavy scenarios, and blocking with conditions for producer‑consumer queues. This ensures safe concurrent access without the performance bottlenecks of synchronized collections."

ConcurrentHashMap Internal Working 🔹 Before Java 8 Segmentation approach was used.

The map was divided into segments (like mini HashMaps).

Each segment had its own lock.

Only one thread could access a segment at a time, but multiple threads could work on different segments concurrently.

This reduced contention compared to a fully synchronized HashMap, but still had overhead.

🔹 Java 8 and Later Segmentation removed → now it’s a single map.

Uses CAS (Compare-And-Swap) for atomic updates.

Buckets are stored as linked lists, and if collisions grow large, they are converted into balanced trees (red-black tree) for faster lookups.

Synchronization happens at the bucket/node level, not the whole map.

Result: lock-free reads and fine-grained updates with much better scalability.

ConcurrentHashMap — concurrent reads, segmented writes

import java.util.concurrent.*;

public class MapDemo {
    public static void main(String[] args) {
        ConcurrentMap<String, Integer> counts = new ConcurrentHashMap<>();

        counts.put("java", 1);
        counts.compute("java", (k, v) -> v + 1);         // atomic update
        counts.merge("java", 1, Integer::sum);           // atomic upsert
        counts.putIfAbsent("rust", 1);                   // no blind overwrite

        // Iterators are fail-safe: no ConcurrentModificationException
        counts.forEach((k, v) -> counts.putIfAbsent("x" + k, v));
    }
}

CopyOnWriteArrayList — reads never block, writes copy the array

import java.util.concurrent.CopyOnWriteArrayList;
import java.util.List;

class Listeners {
    // Perfect for listener registries: rare writes, constant iteration
    private final List<Runnable> listeners = new CopyOnWriteArrayList<>();

    void register(Runnable r) { listeners.add(r); }

    void fire() {
        for (Runnable r : listeners) r.run();   // snapshot — safe even mid-add
    }
}

BlockingQueue: producer-consumer without wait/notify

import java.util.concurrent.*;

class Pipeline {
    public static void main(String[] args) throws InterruptedException {
        BlockingQueue<String> queue = new ArrayBlockingQueue<>(10);

        Thread producer = new Thread(() -> {
            try {
                for (int i = 0; i < 5; i++) queue.put("item-" + i);  // blocks if full
                queue.put("EOF");
            } catch (InterruptedException e) { Thread.currentThread().interrupt(); }
        });

        Thread consumer = new Thread(() -> {
            try {
                String item;
                while (!(item = queue.take()).equals("EOF")) {       // blocks if empty
                    System.out.println(item);
                }
            } catch (InterruptedException e) { Thread.currentThread().interrupt(); }
        });

        producer.start(); consumer.start();
        producer.join(); consumer.join();
    }
}

// | Classic                    | Concurrent replacement            |
// |----------------------------|-----------------------------------|
// | HashMap                    | ConcurrentHashMap                 |
// | TreeMap                    | ConcurrentSkipListMap             |
// | ArrayList (read-mostly)    | CopyOnWriteArrayList              |
// | HashSet                    | ConcurrentHashMap.newKeySet()     |
// | LinkedList as queue        | ConcurrentLinkedQueue             |
// | wait/notify hand-off       | BlockingQueue (Array/Linked)      |
