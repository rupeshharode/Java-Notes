JDBC

Connecting Java to databases: drivers, connections, statements and transactions.

databasesqlcrud

"JDBC stands for Java Database Connectivity. It is a Java API used to establish a connection between a Java application and a relational database. It acts as a bridge between a Java application and a database and allows us to execute SQL queries and perform CRUD operations such as inserting, updating, deleting, and retrieving data from the database."

Important points to remember: it

JDBC is a Java API, not a library for automatic object mapping.

It allows us to execute SQL queries.

It is used to perform CRUD operations.

It requires a database driver to communicate with a specific database

  1. MVC Architecture

MVC stands for Model-View-Controller. It separates an application into three parts.

Component Responsibility

Model Represents application data and business logic.

View Displays data to the user.

Controller Handles user requests and coordinates the flow.

  1. Model Class

A model class represents the data of an application. It generally contains private variables, constructors, getters, and setters.

  1. DAO Class

DAO stands for Data Access Object.

It is responsible for interacting with the database.

It executes SQL queries using JDBC.

It performs CRUD operations such as insert, update, delete, and select.

  1. DTO Class

DTO stands for Data Transfer Object.

It is used to transfer data between different layers of an application.

It can contain only the information required by the receiving layer.

It helps avoid exposing unnecessary fields.

For example, a student database might contain an ID, name, address, and phone number, but a student listing page may need only the ID and name.

The six JDBC steps

import java.sql.*;

public class JdbcDemo {
    public static void main(String[] args) throws Exception {
        // 1. Load the driver (optional since JDBC 4 auto-loading)
        Class.forName("com.mysql.cj.jdbc.Driver");

        // 2. Get a connection
        try (Connection con = DriverManager.getConnection(
                "jdbc:mysql://localhost:3306/school", "root", "password")) {

            // 3. Create a statement
            Statement st = con.createStatement();

            // 4. Execute the query
            ResultSet rs = st.executeQuery("SELECT id, name FROM students");

            // 5. Read results
            while (rs.next()) {
                System.out.println(rs.getInt("id") + " " + rs.getString("name"));
            }
            // 6. try-with-resources closes everything automatically
        }
    }
}

PreparedStatement — always use it for parameters

import java.sql.*;

class SafeInsert {
    static void addStudent(Connection con, String name, int age) throws SQLException {
        String sql = "INSERT INTO students (name, age) VALUES (?, ?)";
        try (PreparedStatement ps = con.prepareStatement(sql)) {
            ps.setString(1, name);   // parameters are escaped — prevents SQL injection
            ps.setInt(2, age);
            int rows = ps.executeUpdate();
            System.out.println(rows + " row inserted");
        }
    }

    static Student findById(Connection con, int id) throws SQLException {
        try (PreparedStatement ps = con.prepareStatement(
                "SELECT id, name, age FROM students WHERE id = ?")) {
            ps.setInt(1, id);
            try (ResultSet rs = ps.executeQuery()) {
                if (!rs.next()) return null;
                return new Student(rs.getInt("id"), rs.getString("name"), rs.getInt("age"));
            }
        }
    }
}

Transactions: all or nothing

import java.sql.*;

class Transfer {
    static void transfer(Connection con, int from, int to, double amount) throws SQLException {
        boolean oldAutoCommit = con.getAutoCommit();
        try {
            con.setAutoCommit(false);                       // begin transaction
            try (PreparedStatement debit = con.prepareStatement(
                     "UPDATE accounts SET balance = balance - ? WHERE id = ?")) {
                debit.setDouble(1, amount); debit.setInt(2, from);
                debit.executeUpdate();
            }
            try (PreparedStatement credit = con.prepareStatement(
                     "UPDATE accounts SET balance = balance + ? WHERE id = ?")) {
                credit.setDouble(1, amount); credit.setInt(2, to);
                credit.executeUpdate();
            }
            con.commit();                                   // both succeeded
        } catch (SQLException e) {
            con.rollback();                                 // undo everything
            throw e;
        } finally {
            con.setAutoCommit(oldAutoCommit);
        }
    }
}
