Exception Handling

Checked vs unchecked, try-catch-finally, throws and custom exceptions.

exceptionstry-catch

An exception is an abnormal condition that disrupts or terminates the normal flow of execution of a program. Exception handling is a mechanism used to handle exceptions, recover from them, and allow the program to continue its execution when possible.

In Java, exceptions are mainly divided into two types:

Checked Exceptions Checked exceptions are checked by the compiler at compile time. The programmer must either handle them using a try-catch block or declare them using throws.

Examples:

IOException

SQLException

FileNotFoundException

Unchecked Exceptions Unchecked exceptions occur at runtime and are subclasses of RuntimeException. The compiler does not require the programmer to explicitly handle them.

Examples:

ArithmeticException

ArrayIndexOutOfBoundsException

ClassCastException

NullPointerException

We can handle exceptions using mechanisms such as try-catch, finally, throw, and throws.

Errors are different from exceptions. Errors generally indicate serious problems that applications normally should not try to recover from.

Examples:

OutOfMemoryError

StackOverflowError

Therefore, exception handling is mainly used to handle conditions from which a program can reasonably recover, rather than serious JVM-level errors.

The throw keyword is used to explicitly throw an exception in Java.

We can create a custom exception by extending the Exception class (for a checked exception) or RuntimeException (for an unchecked exception).

For example, if a person is not eligible to vote when their age is less than 18, we can create a custom exception called NotEligibleForVoteException.

class NotEligibleForVoteException extends Exception { NotEligibleForVoteException(String message) { super(message); } }

public class Voting { public static void main(String[] args) { int age = 16;

    try {
        if (age < 18) {
            throw new NotEligibleForVoteException("Not Eligible to Vote");
        }

        System.out.println("Eligible to Vote");
    } catch (NotEligibleForVoteException e) {
        System.out.println(e.getMessage());
    }
}

}

throw = actually throws an exception throws = declares that a method may throw an exception

The hierarchy: Throwable -> Error / Exception

// Throwable
//  ├── Error          — JVM-level, don't catch (OutOfMemoryError, StackOverflowError)
//  └── Exception
//       ├── RuntimeException (unchecked) — NullPointerException, ArrayIndexOutOfBounds,
//       │                                 ClassCastException, ArithmeticException
//       └── checked          — IOException, SQLException, ClassNotFoundException

try-catch-finally with multiple catches

public class Demo {
    public static void main(String[] args) {
        try {
            int result = 10 / Integer.parseInt(args[0]);
            System.out.println(result);
        } catch (NumberFormatException e) {
            System.out.println("Not a number: " + e.getMessage());
        } catch (ArithmeticException e) {
            System.out.println("Cannot divide by zero");
        } catch (Exception e) {               // broader catch must come last
            System.out.println("Something else: " + e);
        } finally {
            System.out.println("Always runs — even after return");
        }
    }
}

Checked exceptions must be declared or handled

import java.io.IOException;
import java.nio.file.*;

class FileReaderUtil {
    // Option 1: declare with throws and let the caller decide
    static String read(String path) throws IOException {
        return Files.readString(Path.of(path));
    }

    static void demo() {
        try {
            System.out.println(read("notes.txt"));
        } catch (IOException e) {
            // Option 2: handle here
            e.printStackTrace();
        }
    }
}

Custom exceptions

class InsufficientBalanceException extends Exception {          // checked
    public InsufficientBalanceException(double shortfall) {
        super("Short by " + shortfall);
    }
}

class Account {
    private double balance = 100;

    void withdraw(double amount) throws InsufficientBalanceException {
        if (amount > balance) {
            throw new InsufficientBalanceException(amount - balance);
        }
        balance -= amount;
    }
}

try-with-resources and multi-catch

import java.io.*;

class Modern {
    static void copy() throws IOException {
        // AutoCloseable resources close automatically, in reverse order
        try (BufferedReader in = new BufferedReader(new FileReader("a.txt"));
             BufferedWriter out = new BufferedWriter(new FileWriter("b.txt"))) {

            String line;
            while ((line = in.readLine()) != null) out.write(line);
        }
    }

    static void multiCatch(String input) {
        try {
            int n = Integer.parseInt(input);
        } catch (NumberFormatException | NullPointerException e) { // one handler, two types
            System.out.println("bad input");
        }
    }
}
