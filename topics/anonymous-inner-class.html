Anonymous Inner Class

One-off implementations without naming a class.

oopinner classlambdas

An anonymous class is a class that is declared without a class name. It is mainly used when we need to provide an implementation or override methods of an abstract class or an interface without creating a separate named class.

A lambda expression, introduced in Java 8, is a concise way to provide an implementation of the single abstract method (SAM) of a functional interface.

The important difference is:

Anonymous class → can extend an abstract class or implement an interface. It can override abstract methods as well as concrete methods.

Lambda expression → can be used only with a functional interface (an interface having exactly one abstract method). It provides the implementation of that abstract method.

A lambda cannot override a concrete/default method of an interface or a concrete method inherited from Object.

For example:

// Anonymous class Runnable r1 = new Runnable() { @Override public void run() { System.out.println("Running"); } };

Using lambda:

// Lambda expression Runnable r2 = () -> { System.out.println("Running"); };

Both implement Runnable, whose only abstract method is run().

One important correction to your statement is "with the help of these we can't override concrete methods." This is not true for anonymous classes. An anonymous class can override concrete methods.

class A { void show() { System.out.println("A"); } }

A obj = new A() { @Override void show() { System.out.println("Anonymous class"); } };

this in Anonymous Class In an anonymous class, this refers to the anonymous class object itself.

class Test { void show() { Runnable r = new Runnable() { @Override public void run() { System.out.println(this); } };

    r.run();
}

}

Here, this inside run() refers to the anonymous Runnable object, not the Test object.

this in Lambda In a lambda expression, this does not create a new meaning/context. It refers to the this of the enclosing/current class.

class Test { void show() {

    Runnable r = () -> {
        System.out.println(this);
    };

    r.run();
}

}

Here, this inside the lambda refers to the Test object.

Anonymous class implementing an interface

interface Greeter {
    void greet(String name);
}

public class Demo {
    public static void main(String[] args) {
        // A class with no name, defined and instantiated in one expression
        Greeter english = new Greeter() {
            @Override
            public void greet(String name) {
                System.out.println("Hello, " + name);
            }
        };
        english.greet("Jack");
    }
}

Extending a class anonymously (with instance initializer)

import java.util.ArrayList;
import java.util.List;

public class Demo {
    public static void main(String[] args) {
        ArrayList<String> list = new ArrayList<>() {
            {
                add("always");          // instance initializer block
                add("available");
            }

            @Override
            public boolean add(String s) {
                System.out.println("adding: " + s);
                return super.add(s);
            }
        };
        list.add("one more");
    }
}

The classic use: Runnable and event handlers

public class Demo {
    public static void main(String[] args) {
        Thread t = new Thread(new Runnable() {
            @Override
            public void run() {
                System.out.println("Running in " + Thread.currentThread().getName());
            }
        });
        t.start();

        // Same thing as a lambda — a functional interface needs no boilerplate
        new Thread(() -> System.out.println("lambda version")).start();
    }
}

Rules to remember

class Outer {
    private String msg = "from outer";

    void demo() {
        int localVar = 42;   // must be final or effectively final to be captured

        Runnable r = new Runnable() {
            @Override public void run() {
                // can read Outer.this.msg (the outer instance)
                // can read localVar but CANNOT reassign it
                System.out.println(msg + " / " + localVar);
            }
        };
        r.run();
    }
}
