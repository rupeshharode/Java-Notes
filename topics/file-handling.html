File Handling

Reading and writing files with FileReader, BufferedReader, Streams and NIO.

iofilesnio

short->File handling provides persistent storage, meaning data can be stored and retrieved even after the application stops running.

File handling in Java is the process of reading data from a file, writing data to a file, and performing operations on the data stored in a file.

When we create an application, such as a Student Management System, and store student information only in variables or collections in memory, the data is available only during the program's execution. Once the program terminates, that data is lost.

To store data permanently, we can use:

File Handling: Stores data in files such as .txt, .csv, or .dat.

Database: Stores data in a structured format using systems such as MySQL or PostgreSQL.

Example

In a Student Management System, we can use file handling to:

Store student details in a file.

Read student details from the file.

Update student information.

Delete student records.

Simple Java Example import java.io.FileWriter; import java.io.IOException;

public class Main { public static void main(String[] args) { try { FileWriter writer = new FileWriter("student.txt"); // for avoid overeriting we need to pass true 

        writer.write("101, Jack, Java");

        writer.close();

        System.out.println("Data written successfully");
    } catch (IOException e) {
        e.printStackTrace();
    }
}

}

Output:

Data written successfully

This program writes student information to a file named student.txt, allowing the data to remain available after the program terminates.

Important Interview Point

File handling provides persistent storage, meaning data can be stored and retrieved even after the application stops running.

A database is generally preferred for applications that require structured data management, complex queries, and concurrent access.

"In Java, we use FileReader to read character-based data and FileWriter to write character-based data. The read() method of FileReader reads one character at a time, while the write() method of FileWriter writes data to a file. If we want to read data line by line, we use BufferedReader, which provides the readLine() method. Similarly, BufferedWriter helps us write data efficiently using buffering."

import java.io.*;

public class Main { public static void main(String[] args) throws IOException {

    BufferedReader br = new BufferedReader(
            new FileReader("student.txt"));

    String line;

    while ((line = br.readLine()) != null) {
        System.out.println(line);
    }

    br.close();
}

}

Reading text with BufferedReader (classic)

import java.io.*;

class ReadDemo {
    public static void main(String[] args) throws IOException {
        try (BufferedReader reader = new BufferedReader(new FileReader("notes.txt"))) {
            String line;
            while ((line = reader.readLine()) != null) {   // null = end of file
                System.out.println(line);
            }
        }
    }
}

Writing with FileWriter and BufferedWriter

import java.io.*;

class WriteDemo {
    public static void main(String[] args) throws IOException {
        // append = true keeps existing content
        try (BufferedWriter out = new BufferedWriter(new FileWriter("log.txt", true))) {
            out.write("New entry");
            out.newLine();          // platform-independent line break
        }
    }
}

Byte streams for binary data

import java.io.*;

class CopyImage {
    public static void main(String[] args) throws IOException {
        try (FileInputStream in = new FileInputStream("photo.jpg");
             FileOutputStream out = new FileOutputStream("copy.jpg")) {
            byte[] buffer = new byte[8192];
            int bytesRead;
            while ((bytesRead = in.read(buffer)) != -1) {
                out.write(buffer, 0, bytesRead);
            }
        }
    }
}

NIO: the modern approach (java.nio.file)

import java.io.IOException;
import java.nio.file.*;
import java.util.List;

class NioDemo {
    public static void main(String[] args) throws IOException {
        Path path = Path.of("notes.txt");

        List<String> allLines = Files.readAllLines(path);   // small files only
        Files.write(path, allLines, StandardOpenOption.APPEND);

        // Large files: stream lazily
        try (var lines = Files.lines(path)) {
            lines.filter(l -> l.contains("java"))
                 .forEach(System.out::println);
        }

        // Walk a directory tree
        try (var stream = Files.walk(Path.of("."))) {
            stream.filter(Files::isRegularFile)
                  .forEach(System.out::println);
        }
    }
}
