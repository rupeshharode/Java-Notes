Abstraction

Hiding implementation details with abstract classes and interfaces.

oopabstract class

Abstraction means hiding implementation details and showing only the essential information or functionality to the user.

In Java, we can achieve abstraction using the abstract keyword and interfaces.

The abstract keyword can be used with a class or a method.

Abstract Class

An abstract class is a class whose object is not created 

An abstract class can contain:

Fields

Constructors

Concrete methods (methods with implementation)

Abstract methods (methods without implementation)

An abstract method is declared using the abstract keyword and does not have a method body.

abstract class Animal {

String name;

Animal(String name) {
    this.name = name;
}

abstract void sound();

void eat() {
    System.out.println("Animal eats");
}

}

A child class that inherits an abstract class must provide implementations for all abstract methods, unless the child class is also declared abstract.

class Dog extends Animal {

Dog(String name) {
    super(name);
}

@Override
void sound() {
    System.out.println("Dog barks");
}

}

We cannot create an object directly from the abstract class:

// Animal a = new Animal("Tom"); // ❌ Not allowed

But we can create an object of its concrete child class:

Dog d = new Dog("Tom"); // ✅ Allowed

When the Dog object is created, the Animal constructor is also called through super(name) to initialize the inherited name field.

Important Point

An abstract class can have a constructor, even though we cannot create its object directly.

The constructor is useful for initializing the part of the object that comes from the abstract parent class.

In short:

Abstraction = Hide implementation details + Show essential functionality

A class can extend only one class, whether that class is abstract or concrete.

For example:

abstract class Animal { abstract void sound(); }

abstract class Vehicle { abstract void run(); }

class Dog extends Animal { @Override void sound() { System.out.println("Dog barks"); } }

This is not allowed:

class Dog extends Animal, Vehicle { // ❌ Not allowed }

Java does not support multiple inheritance through classes.

However, a class can extend one class and implement multiple interfaces:

class Dog extends Animal implements Runnable, Serializable { // ...

Abstract class: partial implementation + state

abstract class Payment {
    protected double amount;                 // abstract classes CAN have state

    Payment(double amount) { this.amount = amount; }

    abstract void pay();                     // subclasses MUST implement

    void receipt() {                         // shared concrete behaviour
        System.out.println("Paid " + amount);
    }
}

class UpiPayment extends Payment {
    UpiPayment(double amount) { super(amount); }
    @Override void pay() { System.out.println("Paying via UPI"); }
}

Interface: a pure contract (before and after Java 8)

interface Loggable {
    void log(String msg);                    // implicitly public abstract

    default void info(String msg) {          // Java 8+: default method
        log("[INFO] " + msg);
    }

    static Loggable console() {              // Java 8+: static method
        return System.out::println;
    }
}

class AuditService implements Loggable {
    @Override public void log(String msg) { System.out.println(msg); }
}

The key differences side by side

// abstract class Database {}
// interface  Repository {}

// | Feature          | abstract class        | interface                    |
// |------------------|-----------------------|------------------------------|
// | Fields           | any (state allowed)   | public static final only     |
// | Constructors     | yes                   | no                           |
// | Method bodies    | allowed               | default/static/private only  |
// | Multiple         | one class only        | many interfaces              |
// | Use when         | "is-a" + shared code  | capability / contract        |

class Manager extends Employee implements Payable, Taxable { }  // legal
// class Manager extends A, B {}                                 // illegal

Anonymous class to interface — and then to lambda

interface Calculator { int compute(int a, int b); }

class Demo {
    public static void main(String[] args) {
        // old way: anonymous inner class
        Calculator add = new Calculator() {
            public int compute(int a, int b) { return a + b; }
        };

        // Java 8 way: lambda (works because Calculator is functional)
        Calculator multiply = (a, b) -> a * b;

        System.out.println(add.compute(2, 3));      // 5
        System.out.println(multiply.compute(2, 3)); // 6
    }
}
