JSP

JavaServer Pages, directives, scriptlets, JSTL and the MVC pattern.

webviewsel
  1. What is JSP?

JSP (JavaServer Pages) is a server-side technology used to create dynamic web pages by combining HTML with Java-based dynamic content.

It separates the presentation layer (HTML) from the business logic, making web applications easier to develop and maintain.

  1. Why do we use JSP?

Before JSP, developers often used Servlets to generate HTML using PrintWriter. This made the code lengthy and difficult to maintain.

Servlet example:

PrintWriter out = response.getWriter(); out.println(""); out.println(""); out.println("

Welcome " + name + "

"); out.println(""); out.println("");

JSP example (welcome.jsp):

Welcome ${name}

Here, ${name} is an Expression Language (EL) expression that displays the value of the name attribute.

  1. How does JSP work?

Client sends a request

Servlet processes the request

Business logic and data processing

JSP displays dynamic data

HTML + dynamic content

HTML response sent to the browser

Important: A JSP is internally translated into a Servlet by the web container and then compiled and executed.

  1. Ways to write dynamic content in JSP

Syntax Purpose <%= expression %> Prints the value of a Java expression

${name} Displays a value using Expression Language (EL)

<% Java code %> Writes Java code inside a JSP scriptlet

Example:

Welcome <%= request.getAttribute("name") %>

Modern JSP development generally prefers EL and JSTL over scriptlets.

Interview-ready answer

Question: What is JSP, and why do we use it?

JSP stands for JavaServer Pages. It is a server-side technology used to create dynamic web pages by combining HTML with dynamic data.

Before JSP, developers used Servlets to generate HTML using PrintWriter, which made the code lengthy and difficult to maintain. JSP simplifies this by allowing HTML to be written separately and dynamic data to be included using EL expressions.

JSP is internally converted into a Servlet by the web container.

Key interview points

JSP is used for the presentation layer.

Servlets are commonly used for request processing and control flow.

JSP supports Expression Language (EL), JSTL, and JSP actions.

JSP is translated into a Servlet and executed on the server.

JSP is part of the Java web technology stack and is commonly used with MVC architecture.

  1. What is the JSP life cycle?

The JSP life cycle consists of these steps:

Translation of JSP into a Servlet.

Compilation of the Servlet.

Class loading and object creation.

jspInit() — called once during initialization.

_jspService() — handles each request.

jspDestroy() — called before the JSP is removed.

  1. What are JSP implicit objects?

Implicit objects are predefined objects available in JSP without explicitly creating them.

Common examples:

request — handles client request data.

response — sends the response.

session — stores user-specific session data.

application — shares data across the application.

out — writes content to the response.

config — provides JSP configuration.

pageContext — provides access to JSP context and scopes.

page — refers to the current JSP's Servlet instance.

exception — provides exception information on error pages.

What are JSP scripting elements?

There are three main scripting elements:

Element Syntax

Declaration <%! int count = 0; %>

Scriptlet <% int a = 10; %>

Expression <%= a %>

What is Expression Language (EL) in JSP?

EL is used to access data and evaluate expressions without writing Java code directly.

Example:

${user.name}

  1. What is JSTL?

JSTL stands for JavaServer Pages Standard Tag Library. It provides tags for common tasks such as iteration, conditional statements, and formatting, reducing the need for Java scriptlets in JSP.

  1. What are JSP scopes?

JSP has four scopes:

Scope Lifetime

Page Current JSP page execution.

Request Current request.

Session User's session.

Application Entire web application.

A basic JSP page

<%@ page contentType="text/html;charset=UTF-8" language="java" %>
<html>
<head><title>First JSP</title></head>
<body>
    <%-- comment: not sent to the browser --%>

    <% // scriptlet: Java code embedded in the page
       String user = request.getParameter("user");
       if (user == null) user = "guest";
    %>

    <h1>Hello <%= user %>!</h1>              <%-- expression: printed out --%>

    <%! int hitCounter = 0; %>               <%-- declaration: instance level --%>
    <%++hitCounter; %>
    <p>Hits: <%= hitCounter %></p>
</body>
</html>

Directives

<%@ page language="java" import="java.util.Date" %>   <%-- page config --%>
<%@ include file="header.jsp" %>                      <%-- static include at translation --%>
<%@ taglib prefix="c" uri="jakarta.tags.core" %>      <%-- JSTL tag library --%>

JSTL + EL: the preferred style (no scriptlets)

<%@ taglib prefix="c" uri="jakarta.tags.core" %>
<c:forEach var="item" items="${requestScope.cart}">
    <tr>
        <td>${item.name}</td>
        <td>${item.price}</td>
    </tr>
</c:forEach>

<c:if test="${user.role == 'admin'}">
    <a href="/admin">Admin panel</a>
</c:if>

MVC with a servlet controller and JSP view

// Controller (servlet) — fetches data, forwards to the view
import jakarta.servlet.http.*;
import jakarta.servlet.annotation.WebServlet;
import java.util.List;

@WebServlet("/products")
public class ProductController extends HttpServlet {
    @Override
    protected void doGet(HttpServletRequest req, HttpServletResponse resp)
            throws jakarta.servlet.ServletException, java.io.IOException {
        List<String> products = List.of("Laptop", "Phone", "Tablet");
        req.setAttribute("products", products);            // Model passed as attribute
        req.getRequestDispatcher("/products.jsp").forward(req, resp);
    }
}

<%-- View (products.jsp) — only presentation --%>
<c:forEach var="p" items="${products}">
    <li>${p}</li>
</c:forEach>
