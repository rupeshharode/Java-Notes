Interfaces

Contracts in Java: default, static and functional interfaces.

oopinterfacedefault methods

An interface in Java is used to achieve abstraction and can be used to achieve a form of multiple inheritance, because a class can implement multiple interfaces.

An interface acts like a contract or blueprint that specifies what a class should do. The implementing class provides the actual implementation.

Important points about interfaces

An interface does not have a constructor because we cannot create an object directly from an interface.

Interface fields are implicitly public static final, so they are constants.

An interface can contain abstract methods.

An interface can also contain default methods with an implementation.

An interface can contain static methods with an implementation.

Modern Java also allows private methods inside interfaces, mainly to share implementation between interface methods.

A class can implement multiple interfaces.

Example:

interface Animal { int LEGS = 4; // public static final

void sound();  // public abstract

default void eat() {
    System.out.println("Animal eats");
}

static void info() {
    System.out.println("This is an Animal interface");
}

}

class Dog implements Animal {

@Override
public void sound() {
    System.out.println("Dog barks");
}

}

Here, Dog implements the Animal interface and must provide an implementation for the abstract sound() method.

Multiple interfaces

Java allows a class to implement multiple interfaces:

interface A { void methodA(); }

interface B { void methodB(); }

class C implements A, B {

public void methodA() {
    System.out.println("A");
}

public void methodB() {
    System.out.println("B");
}

}

So the key difference is:

Class inheritance:

class Dog extends Animal

Multiple interface implementation:

class Dog implements Animal, Runnable

Easy interview definition

An interface is a contract that defines a set of behaviors that implementing classes must provide. It supports abstraction and allows a class to implement multiple interfaces.

Declaring and implementing an interface

interface Vehicle {
    int MAX_SPEED = 120;                 // public static final by default

    void start();                        // public abstract by default

    default void honk() {                // default method — inherited as-is
        System.out.println("Beep!");
    }

    static void service(Vehicle v) {     // static helper, called on the interface
        System.out.println("Servicing " + v);
    }
}

class Bike implements Vehicle {
    @Override public void start() { System.out.println("Kick start"); }
}

Multiple inheritance of type — and the diamond resolution

interface A {
    default void hello() { System.out.println("A"); }
}

interface B {
    default void hello() { System.out.println("B"); }
}

class C implements A, B {
    @Override public void hello() {          // MUST resolve the conflict
        A.super.hello();                     // pick one explicitly
    }
}

Functional interfaces + the standard ones

@FunctionalInterface
interface Converter<F, T> {
    T convert(F from);
}

import java.util.function.*;

class Demo {
    public static void main(String[] args) {
        Converter<String, Integer> parseInt = Integer::parseInt;

        Function<String, Integer> length = String::length;
        Predicate<String> isEmpty = String::isEmpty;
        Supplier<String> greeting = () -> "hello";
        Consumer<String> printer = System.out::println;

        System.out.println(length.apply("java"));   // 4
        printer.accept(greeting.get());             // hello
    }
}
