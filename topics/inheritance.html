Inheritance

Reusing behaviour across classes with extends, super and the types of inheritance.

oopinheritancesuper

Inheritance means acquiring the properties and behaviors of one class in another class.

In inheritance, the child class inherits accessible fields and methods from the parent class. It helps in code reusability and establishing a relationship between classes.

There are commonly five types of inheritance:

Single Inheritance – One child class inherits from one parent class.

Multilevel Inheritance – A class inherits from another class, which itself inherits from another class.

Hierarchical Inheritance – Multiple child classes inherit from the same parent class.

Multiple Inheritance – One child class inherits from multiple parent classes. Java does not support multiple inheritance through classes, mainly to avoid ambiguity.

Hybrid Inheritance – A combination of two or more types of inheritance.

In Java, multiple inheritance is not supported with classes, but similar behavior can be achieved using interfaces. A class can implement multiple interfaces.

For example:

interface A { void methodA(); }

interface B { void methodB(); }

class C implements A, B { public void methodA() { System.out.println("Method A"); }

public void methodB() {
    System.out.println("Method B");
}

}

Here, class C implements both A and B, so it can provide implementations for methods from both interfaces.

Animal ↓ Dog ↓ Puppy

class Dog extends Animal { void bark() { System.out.println("Dog barks"); } }

class Puppy extends Dog { void play() { System.out.println("Puppy plays"); } }

Basic single inheritance with super

class Vehicle {
    protected String brand;

    Vehicle(String brand) {
        this.brand = brand;
    }

    void start() {
        System.out.println(brand + " is starting");
    }
}

class Car extends Vehicle {
    private int doors;

    Car(String brand, int doors) {
        super(brand);          // must be the first statement
        this.doors = doors;
    }

    @Override
    void start() {
        super.start();         // reuse parent behaviour
        System.out.println("with " + doors + " doors");
    }
}

Java supports these inheritance types (not multiple class inheritance)

// Multilevel: A -> B -> C
class A { void a() {} }
class B extends A { void b() {} }
class C extends B { void c() {} }

// Hierarchical: one parent, many children
class Animal { void eat() {} }
class Dog extends Animal {}
class Cat extends Animal {}

// Diamond problem — why Java forbids multiple class inheritance
// class D extends B, C {}   // compile error: which method wins?

Method hiding vs overriding (static is not polymorphic)

class Parent {
    static void greet() { System.out.println("Parent static"); }
    void hello() { System.out.println("Parent instance"); }
}

class Child extends Parent {
    static void greet() { System.out.println("Child static"); }   // hiding
    void hello() { System.out.println("Child instance"); }        // overriding
}

class Demo {
    public static void main(String[] args) {
        Parent p = new Child();
        p.hello();      // "Child instance"  — runtime polymorphism
        p.greet();      // "Parent static"   — resolved at compile time
    }
}
