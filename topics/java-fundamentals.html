Explain variables in java ?

    what is Variables ?

  • a variable is both a container and a named memory location used to store a data value. Since Java is a statically typed language, we must explicitly declare the data type of a variable at compile time, which ensures type safety and prevents invalid operations

what is Data types ?

"In Java, data types define what kind of values a variable can hold. This ensures type safety (you can’t assign a string to an integer), prevents invalid operations (like adding a number to text), and allows the JVM to perform efficient memory management.

For example, if we want to store a person’s age, using short is sufficient because the range (-32,768 to 32,767) easily covers realistic ages. If we use long instead, it would work but unnecessarily consume more memory, leading to inefficiency. Choosing the right data type is therefore critical for writing optimized and reliable code."

what is conditional statement ?

"In Java, conditional statements are used to make decisions based on a condition. If the condition evaluates to true, a specific block of code executes; otherwise, an alternative path is taken. This allows programs to behave dynamically depending on input or state.

The main types of conditional statements in Java are:

if statement → Executes a block only if the condition is true.

if‑else statement → Provides an alternative block if the condition is false.

if‑else‑if ladder → Used when multiple conditions need to be checked sequentially.

nested if‑else → An if inside another if, useful for complex decision logic.

switch statement → Best for fixed values (like enums, days, menu options)."

switch ->"In Java, a switch statement is used for decision‑making when we have multiple discrete values to check. Unlike an if‑else ladder, which evaluates conditions one by one, the switch directly jumps to the matching case label, making execution faster and cleaner for fixed values.

Each case must end with a break; statement to prevent fall‑through (execution continuing into the next case). If no case matches, the default block executes."

explain loops in java?

"A loop in Java is a block of code that executes repeatedly as long as a given condition evaluates to true. Loops are used to automate repetitive tasks, reduce code duplication, and make programs more efficient." used to traverse array collection

"In Java, loops are classified into two types based on when the condition is checked:

Entry‑Controlled Loops

The condition is evaluated before the loop body executes.

If the condition is false initially, the loop body may not run at all.

Examples: for loop, while loop.

int i = 0;

while (i < 5) {

System.out.println(i);

i++;

}

Exit‑Controlled Loops

The condition is evaluated after the loop body executes.

The loop body runs at least once, even if the condition is false.

Example: do‑while loop.

int i = 0;

do {

System.out.println(i);

i++;

} while (i < 5);

operators in Java ?

"In Java, operators are special symbols used to perform operations on operands. They are the building blocks of expressions and decision‑making in programs. Conceptually, operators can be grouped into three categories:

Unary Operators → operate on a single operand.

Increment/Decrement: ++x, x++, --x, x--

Logical NOT: ! (reverses boolean value)

Unary plus/minus: +x, -x

int a = 5;

System.out.println(++a); // Pre-increment → 6

System.out.println(a--); // Post-decrement → 6 then 5

Binary Operators → operate on two operands.

Arithmetic: +, -, *, /, %

Relational: ==, !=, <, >, <=, >=

Logical: \&\&, ||

Bitwise: \&, |, ^, \~, <<, >>, >>>

int x = 10, y = 20;

System.out.println(x + y); // Arithmetic → 30

System.out.println(x < y); // Relational → true

System.out.println(x \& y); // Bitwise AND

Ternary Operator → shorthand for if‑else.

int max = (x > y) ? x : y;

System.out.println("Max: " + max);

Variables, data types & type safety

public class Variables {
    public static void main(String[] args) {
        byte age = 25;              // 1 byte, -128 to 127
        long population = 8_000_000_000L;
        float price = 19.99f;       // needs the f suffix
        double precise = 19.99;
        char grade = 'A';
        boolean isPassed = true;

        // Widening (automatic) vs narrowing (needs a cast)
        int small = 100;
        long wide = small;          // widening: safe
        int back = (int) wide;      // narrowing: explicit cast required
    }
}

Conditions: if-else ladder and switch

public class Conditions {
    static String grade(int marks) {
        if (marks >= 90) return "A";
        else if (marks >= 75) return "B";
        else if (marks >= 60) return "C";
        else return "F";
    }

    static String day(int n) {
        return switch (n) {              // modern switch expression (Java 14+)
            case 1 -> "Monday";
            case 7 -> "Sunday";
            default -> "Weekday";
        };
    }
}

Loops: when the condition is checked matters

public class Loops {
    public static void main(String[] args) {
        for (int i = 1; i <= 5; i++) {          // entry-controlled
            System.out.println("for: " + i);
        }

        int j = 1;
        while (j <= 5) {                        // checks first, may run 0 times
            System.out.println("while: " + j);
            j++;
        }

        int k = 10;
        do {                                    // runs at least once
            System.out.println("do-while: " + k);
            k++;
        } while (k < 5);
    }
}

String immutability and == vs .equals()

public class Strings {
    public static void main(String[] args) {
        String a = "java";              // goes into the String pool
        String b = "java";
        String c = new String("java");  // new heap object

        System.out.println(a == b);        // true  — same pool reference
        System.out.println(a == c);        // false — different objects
        System.out.println(a.equals(c));   // true  — compares characters

        // Immutable: every "change" creates a new object
        String name = "jack";
        name.concat(".dev");               // result thrown away
        System.out.println(name);          // still "jack"
        name = name.concat(".dev");        // reassign the reference instead
        System.out.println(name);          // "jack.dev"
    }
}
