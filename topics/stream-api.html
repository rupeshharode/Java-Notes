Stream API

Declarative data processing: map, filter, reduce and collectors.

java 8streamslambdascollectors

“In Java, the term Stream is used in two different contexts.

First, Java I/O Streams are used to read and write data, such as InputStream, OutputStream, Reader, and Writer.

Second, Java Stream API, introduced in Java 8, is used to process data from collections or other data sources in a functional or declarative way.

A Stream API is a pipeline which is generally consists of three parts: source, intermediate operations, and terminal operation.

The source can be a collection, array, or Stream.of(). Intermediate operations such as filter(), map(), sorted(), and distinct() transform the stream but they are lazy. Means They don't process the data until a terminal operation is invoked.

Terminal operations such as collect(), forEach(), count(), reduce(), and findFirst() trigger the processing and produce a result.

For example:

List result = numbers.stream() .filter(n -> n % 2 == 0) .map(n -> n * 2) .collect(Collectors.toList());

Here, numbers.stream() is the source, filter() and map() are intermediate operations, and collect() is the terminal operation.

So, Stream API is mainly used to process data efficiently and express operations on data in a clean and declarative way.”

If interviewer asks: "What is lazy evaluation?"

Say:

“Lazy evaluation means intermediate operations are not executed immediately. They are executed only when a terminal operation is invoked.”

For example:

numbers.stream() .filter(n -> n > 10) .map(n -> n * 2);

Nothing is actually processed yet.

When we add:

.collect(Collectors.toList());

the pipeline gets executed.

Remember this interview formula

Stream API:

Source ↓ Intermediate Operations ↓ Terminal Operation

Some Methods of Intermediate operation ->

List result = numbers.stream() .filter(n -> n > 10) // intermediate .map(n -> n * 2) // intermediate .distinct() // intermediate .sorted() // intermediate .limit(5) // intermediate .collect(Collectors.toList()); // terminal

Some Terminal Operation ->

forEach() collect() reduce() count() min() max() findFirst() findAny() anyMatch() noneMatch()

Parallel Stream :- // it uses a fork join common pool for parallel processing

“A Parallel Stream is a feature of the Java Stream API that allows stream elements to be processed in parallel using multiple threads, instead of processing them sequentially in a single thread. It can improve performance when processing large amounts of independent data, especially on multi-core systems.”

numbers.parallelStream() .filter(n -> n % 2 == 0) .map(n -> n * 2) .collect(Collectors.toList());

parallel stream not always faster

“Parallel streams can improve performance for suitable workloads, but they also have overhead. For small datasets or operations that are not suitable for parallel execution, a sequential stream can be faster.”

List result = new ArrayList<>();

numbers.parallelStream() .forEach(n -> result.add(n)); // unsafe // race condition

List numbers = List.of(1, 2, 3, 4, 5, 6);

numbers.parallelStream() .forEach(n -> System.out.println( n + " - " + Thread.currentThread().getName() ));

The pipeline: source -> intermediate ops -> terminal op

import java.util.*;
import java.util.stream.*;

class Basics {
    public static void main(String[] args) {
        List<String> names = List.of("Jack", "Riya", "Aman", "Ankit");

        List<String> result = names.stream()          // source
                .filter(n -> n.startsWith("A"))       // intermediate (lazy)
                .map(String::toUpperCase)             // intermediate (lazy)
                .sorted()                             // intermediate (lazy)
                .collect(Collectors.toList());        // terminal — nothing ran until here

        System.out.println(result);   // [AMAN, ANKIT]
    }
}

map vs flatMap

import java.util.*;
import java.util.stream.*;

class Shapes {
    public static void main(String[] args) {
        // map: one in, one out
        List<Integer> lengths = Stream.of("java", "spring")
                .map(String::length)
                .collect(Collectors.toList());        // [4, 6]

        // flatMap: many in, flattened out
        List<List<Integer>> nested = List.of(List.of(1, 2), List.of(3, 4));
        List<Integer> flat = nested.stream()
                .flatMap(List::stream)
                .collect(Collectors.toList());        // [1, 2, 3, 4]
    }
}

reduce and Collectors

import java.util.*;
import java.util.stream.*;

class Aggregate {
    record Employee(String name, String dept, int salary) {}

    public static void main(String[] args) {
        List<Employee> staff = List.of(
                new Employee("Jack", "IT", 90000),
                new Employee("Riya", "IT", 75000),
                new Employee("Sam", "HR", 60000));

        int total = staff.stream().mapToInt(Employee::salary).sum();      // 225000
        Optional<Employee> top = staff.stream()
                .reduce((a, b) -> a.salary() >= b.salary() ? a : b);

        // Grouping — the interview favourite
        Map<String, List<Employee>> byDept = staff.stream()
                .collect(Collectors.groupingBy(Employee::dept));

        Map<Boolean, List<Employee>> partitioned = staff.stream()
                .collect(Collectors.partitioningBy(e -> e.salary() > 70000));

        Map<String, Integer> salaryByDept = staff.stream()
                .collect(Collectors.groupingBy(Employee::dept,
                        Collectors.summingInt(Employee::salary)));

        String names = staff.stream()
                .map(Employee::name)
                .collect(Collectors.joining(", "));   // Jack, Riya, Sam
    }
}

Streams are lazy, single-use, and not a data store

import java.util.stream.*;

class Gotchas {
    public static void main(String[] args) {
        // Lazy: no output until the terminal op
        Stream<Integer> s = Stream.of(1, 2, 3).peek(System.out::println); // prints nothing yet

        // Single-use: a consumed stream throws IllegalStateException
        Stream<Integer> once = Stream.of(1, 2, 3);
        once.count();
        // once.count();   // IllegalStateException: stream has already been operated upon

        // Parallel streams: only for CPU-bound work on big, splittable sources
        long count = LongStream.rangeClosed(1, 10_000_000).parallel()
                .filter(n -> n % 2 == 0)
                .count();
    }
}
